# ChatHackers Website

This is a react project for the chathackers.uk static site.

The site is served from github pages, so we have to build it locally and output to the /docs folder, this is then what is seen online.

## Getting started

1. `npm run dev` to view the site locally 
1. `npm run build` to build the site.
1. `git push` to main or merge to main to deploy to github pages
